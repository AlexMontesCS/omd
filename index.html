Quick Start

Install, render an equation, and add a visualization in minutes.

Install

npm install @teachinglab/omd

Docs: Getting started

Render an Equation

import { omdDisplay, omdEquationNode } from '@teachinglab/omd';

const root = document.getElementById('math');
const display = new omdDisplay(root);

const equation = omdEquationNode.fromString('2x + 3 = 11');
display.render(equation);

API: omdDisplay · omdEquationNode

Step-by-Step Stack

import { omdEquationStack } from '@teachinglab/omd';

const steps = ['2x + 3 = 11', '2x = 8', 'x = 4'];
const stack = new omdEquationStack(steps);
display.render(stack);

API: EquationStack · Step Visualizer

Visualization via JSON

import { createFromJSON } from '@teachinglab/omd';

const numberLine = createFromJSON({
  omdType: 'numberLine',
  min: 0, max: 10,
  dotValues: [2, 5, 8]
});

display.render(numberLine);

Usage Recipes

Copy/paste snippets for the most common flows.

Canvas with Multiple Expressions

import { omdCanvas } from '@teachinglab/omd';

const canvas = new omdCanvas({
  width: 800,
  height: 300,
  expressions: ['x + 4 = 12', '3x - 2 = 10']
});

canvas.attachTo('#math-canvas');

Docs: omdCanvas

Coordinate Plane with Function Graph

import { omdCoordinatePlane } from '@teachinglab/omd';

const plane = new omdCoordinatePlane();
plane.loadFromJSON({
  xMin: -6, xMax: 6, yMin: -6, yMax: 6,
  graphEquations: [{ equation: 'y = x^2 - 4', color: '#ff7b72' }]
});

display.render(plane);

Guide: Coordinate plane

JSON Factory (AI / Config-Driven)

import { createFromJSON } from '@teachinglab/omd';

const tape = createFromJSON({
  omdType: 'tapeDiagram',
  bars: [{ value: 6, label: 'A' }, { value: 9, label: 'B' }],
  showGrid: true
});

display.render(tape);
